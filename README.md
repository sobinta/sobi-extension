# ویرایشگر کدویژن (CodeVision Extension)

یک اکستنشن حرفه‌ای و مدرن برای گوگل کروم (Manifest V3) که به شما اجازه می‌دهد کدهای وب (HTML، CSS و JavaScript) خود را به صورت کاملاً زنده، زرق‌و‌برق‌دار و آفلاین در یک محیط زیبا با طراحی شیشه‌ای (Glassmorphism) بنویسید و پیش‌نمایش آن را در لحظه تماشا کنید.

---

## امکانات جدید و ارتقایافته نسخه اکستنشن

1. **رنگ‌آمیزی هوشمند کدها (Syntax Highlighting):** ادغام موتور رنگ‌آمیزی کدهای قدرتمند **CodeMirror 5** به صورت کاملاً آفلاین جهت تشخیص کلمات کلیدی، پرانتزها و تگ‌های HTML.
2. **کنسول خروجی داخلی (Console Log Viewer):** ثبت و نمایش لحظه‌ای خروجی‌های `console.log` و خطاهای رخ‌داده در جاوااسکریپت با فرمت‌بندی هوشمند و رنگ‌های تفکیک‌شده (Log, Warn, Error).
3. **تفکیک کدها به صورت تب (Tabs Layout):** سه بخش کاملاً مجزا برای نوشتن کدهای HTML، CSS و JS به صورت سازمان‌یافته با حفظ تاریخچه ویرایش و مکان‌نما.
4. **مدیریت پروژه‌ها (Project Manager):** امکان ایجاد بی‌نهایت پروژه، نام‌گذاری مجدد، ذخیره‌سازی ابری/محلی در ذخیره‌ساز مرورگر (`chrome.storage.local`) و حذف آن‌ها از داخل سایدبار کشویی.
5. **تزریق‌کننده کتابخانه‌ها (Library Injector):** افزودن و حذف سریع فریم‌ورک‌ها و کتابخانه‌های محبوب (Tailwind CSS، Bootstrap، FontAwesome، jQuery، React، Animate.css) با یک کلیک.
6. **واردکننده هوشمند فایل (HTML Parser):** قابلیت انتخاب یک فایل HTML تک‌فایلی معمولی و جداسازی خودکار تگ‌های `<style>` و `<script>` آن در تب‌های مربوطه.
7. **پشتیبان‌گیری کامل (Backup & Restore):** امکان خروجی گرفتن از کل دیتابیس پروژه‌ها به صورت یک فایل JSON و بازیابی مجدد آن در دستگاه‌های دیگر.
8. **تنظیمات اختصاصی (Settings Panel):** پنلی برای تغییر سایز قلم ویرایشگر، تغییر اندازه تورفتگی Tab (فاصله ۲ یا ۴)، فعال/غیرفعال کردن رندر خودکار و ذخیره خودکار.

## راهنمای نصب روی گوگل کروم (به صورت Developer Mode)

نیازی به آپلود یا کامپایل پروژه نیست. برای استفاده از این ابزار به عنوان یک اکستنشن کروم، مراحل زیر را طی کنید:

1. مرورگر گوگل کروم (یا هر مرورگر مبتنی بر Chromium مانند Edge یا Brave) را باز کنید.
2. به بخش اکستنشن‌ها بروید (آدرس `chrome://extensions` را در نوار آدرس تایپ کنید).
3. گزینه **Developer mode** (حالت توسعه‌دهنده) را در گوشه سمت راست بالای صفحه فعال کنید.
4. روی دکمه **Load unpacked** (بارگذاری اکستنشن بدون بسته) در گوشه سمت چپ بالای صفحه کلیک کنید.
5. پوشه اصلی پروژه (`sobi-editor`) را انتخاب کنید.
6. اکنون آیکون بنفش‌رنگ **کدویژن** به نوار ابزار مرورگر شما اضافه شده است. با کلیک بر روی آن، استودیو توسعه وب زنده در یک تب جدید و بزرگ در اختیارتان قرار می‌گیرد!

## ساختار دایرکتوری پروژه

- `manifest.json`: ساختار پیکربندی اکستنشن نسخه ۳ (Manifest V3)
- `background.js`: سرویس‌ورکر پس‌زمینه جهت راه‌اندازی ابزار در تب جدید
- `index.html`: ساختار و پنل‌های رابط کاربری
- `style.css`: استایل‌دهی‌های اختصاصی بر پایه طراحی شیشه‌ای (Glassmorphism)
- `app.js`: کدهای منطقی نرم‌افزار، مدیریت دیتابیس پروژه‌ها، رندر لایو، ثبت لاگ‌ها و تفکیک فایل‌ها
- `lib/`: کتابخانه‌های لوکال CodeMirror برای استفاده بدون نیاز به اینترنت (آفلاین)
- `icons/`: آیکون‌های استاندارد اکستنشن در ابعاد ۱۶، ۴۸ و ۱۲۸ پیکسل
